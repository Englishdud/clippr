# Clippr.ai

A local-only AI video clipping web app. Paste a video URL, and Clippr.ai automatically:

1. Downloads the video (YouTube, Twitter/X, TikTok, Instagram)
2. Detects the most energetic highlight segment (30–60s)
3. Reformats to vertical 9:16 (1080×1920)
4. Generates and burns in captions using local Whisper
5. Exports a clean MP4 — no watermark, no external APIs

---

## System Prerequisites

- **Python 3.10+**
- **Node.js 18+**
- **ffmpeg** (must be on your PATH)

### Install ffmpeg

```bash
# macOS
brew install ffmpeg

# Ubuntu / Debian
sudo apt install ffmpeg

# Windows (winget)
winget install ffmpeg
```

```
│   ├── main.py        # API endpoints + pipeline orchestration

│   ├── clipper.py     # librosa highlight detection + ffmpeg processing

│   └── requirements.txt
├── exports/           # Final MP4s (served for download)
│   └── queue/         # Clips generated by auto_pipeline.py (auto-created)
├── temp/              # Intermediate files (auto-cleaned after export)
├── auto_pipeline.py   # Batch automation script
├── watchlist.txt      # Keywords for auto_pipeline.py (one per line)
└── README.md
```

## Backend Setup

```bash
cd backend

# Create and activate virtual environment
python -m venv venv
source venv/bin/activate        # Windows: venv\Scripts\activate

# Install dependencies
pip install -r requirements.txt
```

> **Note:** On first run, Whisper will automatically download the `base` model (~150 MB) and cache it locally. Subsequent runs use the cached model.

## Running the App

Open two terminals:

**Terminal 1 — Backend**
```bash
cd backend
source venv/bin/activate        # Windows: venv\Scripts\activate
uvicorn main:app --reload --port 8000
```

**Terminal 2 — Frontend**
```bash
cd frontend
npm run dev
```

Then open **http://localhost:5173** in your browser.

## Usage

1. Paste a video URL (YouTube, TikTok, Twitter/X, Instagram)
2. Click **Generate Clip**
3. Wait while the pipeline runs (progress shown on screen):
   - Downloading video
   - Detecting highlight
   - Cutting clip
   - Reformatting to 9:16
   - Generating captions
   - Burning captions
4. Click **Download Clip** when ready

## Auto-Pipeline (Batch Mode)

`auto_pipeline.py` automates the full pipeline: it reads keywords from `watchlist.txt`, searches YouTube for the top 5 videos per keyword using yt-dlp, submits each URL to the running backend, and saves finished clips to `exports/queue/`.

### `watchlist.txt` syntax

```
# Lines starting with # are comments — ignored
# Blank lines are ignored
# A bare PAUSED line (case-insensitive) pauses all processing immediately

funny moments
fails compilation
basketball highlights 2024
```

| Line | Effect |
|------|--------|
| `funny moments` | Searches YouTube for "funny moments", processes top 5 results |
| `# comment` | Ignored |
| `PAUSED` | Script exits immediately with a pause message — remove to resume |

### Running the auto-pipeline

The backend must already be running. Use the same venv:

```bash
# Terminal 1 — backend (if not already running)
cd backend
source venv/bin/activate        # Windows: venv\Scripts\activate
uvicorn main:app --port 8000

# Terminal 2 — run the pipeline
source backend/venv/bin/activate
python auto_pipeline.py
```

Finished clips are saved to `exports/queue/` with descriptive names:
```
exports/queue/funny_moments__guy_falls_off_bike_compilation.mp4
exports/queue/funny_moments__try_not_to_laugh_challenge.mp4
```

The script prints live progress — a dot per poll interval — and shows the AI-generated title for each completed clip.

## Notes

- All processing is local — no data leaves your machine
- Exported clips are saved to `exports/` and are yours to keep
- Intermediate files in `temp/` are automatically deleted after export
- The `small` Whisper model is used for captions; change to `base` (faster) or `medium` (more accurate) in `backend/captions.py`
